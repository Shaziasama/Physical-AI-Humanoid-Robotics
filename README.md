# Physical AI & Humanoid Robotics — Essentials

This project aims to create a short, clean, professional AI-Native textbook based on the Physical AI & Humanoid Robotics course. The book will serve as a fast, simple, high-quality learning resource built with a modern Docusaurus UI and a fully integrated free-tier RAG chatbot.

For a detailed understanding of the project's core principles, scope, features, constraints, and success criteria, please refer to the [Project Constitution](.specify/memory/constitution.md).
